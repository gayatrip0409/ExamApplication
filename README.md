# Exam Application System

A full-stack web application for managing exams, students, and results.

---

## Tech Stack

Frontend:

* React.js
* HTML, CSS, JavaScript

Backend:

* Node.js
* Express.js

Database:

* MySQL

---

## Features

* User authentication (login and registration)
* Create and manage exams
* Manage questions
* View results
* Secure backend APIs

* Add admin dashboard
* Improve UI and user experience
